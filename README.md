# ☕ BLEND 블랜드

블록체인 기반 통합 마일리지 서비스

블록체인의 스마트 컨트랙트를 웹에 접목하여 카페 마일리지를 적립하고, 적립된 마일리지가 투명하게 거래되는 것을 보여주는 서비스입니다.

![image.png](image.png)

## 개발 목표

React 학습 이후 이를 실무 수준으로 활용하기 위해, 프론트엔드 팀원으로서 프로젝트에 참여하는 것을 목표로 했습니다.

상태 관리를 통한 UI 제어와 styled-components를 활용한 컴포넌트 설계를 중심으로 모던 웹 개발 방식에 대한 이해를 높였습니다.

## 프로젝트 정보

- 개발 인원: 6명
- 사용 기술
    - React, JavaScript
    - node.js
    - MySQL
- 맡은 역할
    - 메뉴/마이페이지/마일리지 현황/지갑 현황 구현
    - UX/UI 구현
